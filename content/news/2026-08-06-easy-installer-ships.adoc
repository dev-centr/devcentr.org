= DevCentr's new install tool, Ibex, released
:description: Ibex (Install Builder EXtension) — CLI and Explorer actions for installer projects, in-place PATH installs, and CI pipeline emit.
:revdate: 2026-08-06
:keywords: news, blog, Ibex, PATH, installers, plugins, CI, DevCentr

DevCentr's new install tool is out: **Ibex** (Install Builder EXtension). It turns "put this folder on PATH" and "build an installer from this tree" into something you can right-click or script. The CLI is `ibex`.

The first beat is deliberately small. **Install in-place (add to PATH)** means what it says — append the folder to the user PATH, keep a ledger so you can undo, and skip the copy-into-Program-Files ritual when you are iterating on a CLI. File Explorer gets a menu for it (Win11 modern when the sparse package builds; classic cascade otherwise). Linux and macOS get file-manager actions too.

The second beat is the project file. `installer.kdl` plus plugins: portable zip always works; NSIS and Inno emit scripts and call their compilers when present; MSI/MSIX call link:https://github.com/dev-centr/msi-generator[msi-generator]; AppImage gets a stub path on Linux. Optional designer GUIs are discoverable (`plugins install-gui`) instead of reinvented inside our IDE.

CI ships in the same cut. Edit `ci-runner.sdl`, run `emit-ci`, and get runner YAML plus `CI-INSTALLER.adoc` (how to enable pipelines, secrets, tags, and artifact downloads). Local `build` stays optional for smoke tests. Emitters in this release: GitHub Actions, GitLab CI, Azure Pipelines, Jenkins (Declarative), CircleCI, and Bitbucket Pipelines. DevCentr's New Installer dialog can choose **CI pipeline only**; Explorer gets **New Installer CI pipeline** (`--mode=emit-ci`).

DevCentr picks up the same verbs — New → Installer Project, toolbar **Install in-place PATH**, and CLI modes — so the OS menu and the app are not two products pretending to be one.

Docs: link:https://docs.devcentr.org/tools/ibex/latest/index.html[Ibex] · link:https://docs.devcentr.org/tools/ibex/latest/howto-emit-ci.html[emit CI how-to] · link:https://github.com/dev-centr/ibex-install-builder/releases[releases].
