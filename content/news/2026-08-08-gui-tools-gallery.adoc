= GUI tools outside the suite
:description: Screenshots and a feature index for Dev-Centr’s standalone developer GUIs — RepoDrive, Issues Browser, Rules Manager, GitHub Actions Editor, FixNow, and the workflow templates store.
:revdate: 2026-08-08
:keywords: news, blog, RepoDrive, Issues Browser, Rules Manager, GitHub Actions Editor, FixNow, screenshots, GUI

DevCentr the suite is still cooking. Meanwhile the org already ships (or nearly ships) a handful of **standalone GUIs** that do one job well. We ran them with demo data and captured the surfaces that matter — not a changelog dump, a visual index you can skim.

Some shots are live product UI. A few (Actions Editor auth/editor chrome, workflow-templates submit, Rules tray menu) are idealized stand-ins where the real binary needs a toolchain we did not have on the capture machine, matching the Easy Installer “idealized UI” precedent.
