= Partnership with OpenShellOrg
:description: DevCentr and OpenShellOrg lock the sibling story: toolchain ownership here, shell entrypoint honesty there.
:revdate: 2026-07-28
:keywords: news, OpenShellOrg, partnership, shell

DevCentr and OpenShellOrg formalized a sibling partnership: toolchain ownership on the DevCentr side, shell entrypoint honesty on theirs.

The split keeps install and development tools from pretending to be the user's shell — and keeps the shell from pretending to own the toolchain.
