== Problem (one sentence)

Local model runners should register once in a **neutral format** so editors and aggregators discover them without each app inventing its own JSON drop folder.

== Boundaries

* **OPR** answers *what runners exist and how to reach them* — not routing which model to use for a job.
* **UniProvider** is a reference implementation; other aggregators may speak OPR without depending on it.
* **OPR Directory** is for publicly reachable providers; localhost runners stay on disk via UniProvider.
* **MarkView** (September news) is a third-party *viewer* for people's machines — not an in-app or org-docs renderer. See general-knowledge link:https://docs.devcentr.org/general-knowledge/explanation/documentation/markdown-editors-on-disk.html[Markdown editors on local disk].
