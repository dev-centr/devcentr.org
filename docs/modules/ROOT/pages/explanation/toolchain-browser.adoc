= Toolchain Browser
:navtitle: Toolchain Browser
:description: Public toolchain browser on devcentr.org and GitHub Pages, synced from this repo’s SDL definitions. Advice is a feature of the browse flow.

`/toolchain-browser` embeds the **Toolchain Browser** package from `dev-centr/toolchain-advisor` (`web/`).
A standalone SPA also deploys from that repo to https://dev-centr.github.io/toolchain-advisor/[GitHub Pages].

`/toolchain-advisor` redirects here for old links.

== Modes

* **Guided path** — preloads a typical stack; focus one level at a time; breadcrumb jumps.
* **Build filters** — DIY: unlock levels with “Add filter level”; unset levels do not constrain advice.

== Data path

. `scripts/sync-advisor-catalog.mjs` copies `catalog/advisor.sdl` from a `toolchain-advisor` checkout.
. It compiles SDL to JSON via `toolchain-advisor/scripts/compile-sdl.mjs`.
. Outputs land in `public/catalog/advisor.json` and `public/catalog/advisor.sdl`.
. `@dev-centr/toolchain-browser` (aliased to `toolchain-advisor/web`) loads the JSON at runtime.

CI checks out `dev-centr/toolchain-advisor` into `toolchain-advisor/` before sync.
Locally, place a sibling clone at `../toolchain-advisor` or run `pnpm sync-advisor` after cloning.

If compilation fails but a committed `advisor.json` exists in the definitions repo, the sync script falls back to that file.
