== Provenance and verification

`public/news/media/playtime-diagrams.provenance.json` records the canonical
repository, exact commit, source paths, public paths, variants, and SHA-256
digests.

Run `pnpm news:diagrams:sync` with `GENERAL_KNOWLEDGE_REPO` pointing to the
canonical clone to refresh from the pinned commit. Run
`pnpm news:diagrams:check` to detect local drift. CI additionally compares every
artifact byte-for-byte with the pinned commit, validates XML/accessibility and
safety contracts, and exercises adaptive and host modes in Chromium.
