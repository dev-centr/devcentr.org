== Summary

The homepage “Go further” block is an animated DevCentr system: a compact teal-white dwarf and eight orbiting destination planets instead of a static node ring.

== Changed

* Overlapping elliptical orbits; planets pass behind the star on the far side (half size, half opacity) and brighten as they come forward.
* Lighting on each globe tracks the vector toward the dwarf.
* Hover/focus fades in a one-word label (`Skills` not Agent skills). GitHub uses the Octocat mark; other bodies use first-party glyphs.
