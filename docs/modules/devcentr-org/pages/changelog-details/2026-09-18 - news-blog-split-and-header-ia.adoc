== Separate News and Blog channels

`/blog` is no longer an SEO alias of `/news`.

* **News** (`content/news/`, `/news`) — outward shared record: releases, partnerships, openings.
* **Blog** (`content/blog/`, `/blog`) — inward craft: investigations, orientations, critiques.

`scripts/build-news.mjs` emits separate JSON catalogs, routes, and RSS/Atom feeds under `public/news/` and `public/blog/`.

== Header information architecture

`src/components/site-header.tsx` groups public surfaces into dropdowns:

* **Assets** — `/assets` hub, `/apps`, `/skills`, `/assets/standards`
* **Updates** — `/news`, `/blog`, `/changelog`, plus external docs
* **Help** — `/help`, `/status`, GitHub Discussions
* **Links** — org GitHub and Slack

The former single **Community** menu is split into Help and Links.

== Apps catalogue split

Apps routes remain under `/apps` (products, services, standards). The `/assets` gate introduces Apps vs Standards panes; standards also surface at `/assets/standards`.

== Crawlability

`scripts/site-routes.mjs` lists `/blog` and blog post slugs for prerender and sitemap generation. The sitemap includes News and Blog URLs; only `/health` and `/status` are omitted.
