== Title markup (`titleHtml`)

`scripts/build-news.mjs` loads authored posts with AsciiDoc `` `showtitle: false` `` and inspects the document title:

* Plain titles → single `title` string (feeds, `<title>`, list cards).
* Titles containing HTML tags (for example `` = Announcing `envsafe` for Agentic coding`` after AsciiDoc inline passthrough) → add optional `titleHtml` while `title` stays a tag-stripped plain string.

Solid routes (`src/routes/news/*`, `src/routes/blog/*`, home teasers) render `titleHtml` with `innerHTML` on headings only when present; meta tags and RSS still use the plain `title`.
