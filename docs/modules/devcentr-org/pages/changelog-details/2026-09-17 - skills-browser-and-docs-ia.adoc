== Skills catalog UX

`/skills` is framed as a *harness inventory*, not a skill storefront:

* Category tabs switch client-side without a full page reload; the selected category syncs to `?cat=` in the URL.
* Copy actions emit paste-into-agent prompts (including a harness-wide preinstall block), not bare skill names.
* On-page copy distinguishes one-off skill use from installing `dev-centr/agent-rules` as a cohesive harness unit.
* Layout fixes: stable stage height, Bootstrap tab label, full-width option cage, and favicon hub/satellite radius parity in the solar diagram.
