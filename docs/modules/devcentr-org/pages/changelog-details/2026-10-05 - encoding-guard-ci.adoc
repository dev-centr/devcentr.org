== Problem

Double-encoded UTF-8 (classic mojibake from Windows PowerShell 5.1 rewrites) can land in tracked text without breaking the build until someone reads the file.

== Guard workflow

`.github/workflows/encoding-guard.yml` reuses `dev-centr/agent-rules/.github/workflows/encoding-guard.yml@main`.

The check fails when tracked text matches known mojibake signatures or UTF-16 text where UTF-8 is expected.

== Opt-outs

* Per-line: `mojibake-guard: allow` in the file
* Per-path: globs in `.encoding-allow` at the repo root
