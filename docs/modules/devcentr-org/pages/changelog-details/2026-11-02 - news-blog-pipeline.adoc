== Inline markup in titles

Posts whose AsciiDoc titles include inline markup (for example +`envsafe`+ monospace) used to show raw `<code>` tags in page headings.

`scripts/build-news.mjs` now stores:

* `title` — plain text for feeds, meta tags, and JSON-LD (HTML stripped)
* `titleHtml` — optional rendered title when the source title contains markup

Solid routes in `src/routes/news/` and `src/routes/blog/` prefer `titleHtml` in the visible heading when present.

== News post route regression

A metadata bug in `src/routes/news/[slug].tsx` used backslash-escaped quotes in the `keywords` meta string.
Vinxi's file router stopped matching individual news slugs, so `/news/<slug>/` rendered blank until the meta values were corrected.
