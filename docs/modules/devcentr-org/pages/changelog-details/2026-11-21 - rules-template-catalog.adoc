== Rules templates in the extensions store

`/rules` is the rules editor. The panel on the right lists template links kept in this browser. **Install more templates** opens `/extensions`.

`/extensions` searches the extensions catalog and filters by kind. Rules templates are the kind included now. Install appends `install.pointer` and does not store the template body.

The catalog file is `src/data/extensions-catalog.json`, copied from `dev-centr/devcentr` `catalog/extensions.json` when that checkout is next to this repo. The schema notes live in the DevCentr app repository.

`/demos` indexes the same editor.
