== Montserrat for body and headings

Paragraphs and headings both used Space Grotesk. The site now sets the sans and the display face to Montserrat. Nav labels, menu items, and button labels stay IBM Plex Mono.

The fonts ship from the site build. The page preloads the Latin Montserrat file and the Latin Plex Mono weights the chrome uses.
