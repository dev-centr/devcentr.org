== Homepage hero copy is centered

The fixed-height hero left the title and buttons toward the top, because the column was only as tall as the copy and the bottom padding was larger than the top. From the medium breakpoint up, that column now fills the 640px hero and centers the copy with equal padding. Narrow screens still size to the copy.
