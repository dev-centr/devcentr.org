== Hero alignment and JetBrains Mono buttons

Montserrat leaves space to the left of the capital D. At headline size that gap reads as an indent. The hero title uses a start margin of `-0.08em` so the ink of the D meets the paragraph edge.

Button labels now use JetBrains Mono at the same uppercase tracking. The nav and the other small labels stay IBM Plex Mono.
