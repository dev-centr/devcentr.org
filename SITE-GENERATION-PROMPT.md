# Site generation prompt for devcentr.org

Vision and content for the official **DevCentr** organization landing page.

## Context

- **Domain:** https://devcentr.org
- **Hosting:** GitHub Pages (static SolidStart build; custom domain)
- **Mission:** Developer productivity for human and human-in-the-loop AI workflows
- **Category:** Development Orchestration Suite (DOS)

## Design (do not regress)

- Cool steel neutrals + teal signal — **not** cream/serif/terracotta, **not** purple glass, **not** broadsheet rules
- Brand-first hero: wordmark **DevCentr** is the hero signal; one headline; one supporting sentence; CTA group; full-bleed orbital visual
- No cards in the hero; cards only for real interactions
- Fonts: Space Grotesk + IBM Plex Mono
- Motion: orbit / reverse orbit / hub pulse

## Content pillars

1. Ecosystem Management — environment as code
2. Visual DevEx — systems made visible
3. AI Synergy — context that compounds
